# data/

No se suben datos crudos. Aquí solo van:

- manifiestos (qué archivo, de dónde, cuándo se descargó),
- checksums (sha256) para poder comprobar que se trabaja con el mismo dato,
- notas sobre condiciones de uso de cada cohorte.

Los datos descargados viven en `data/raw/`, que está en `.gitignore`.
